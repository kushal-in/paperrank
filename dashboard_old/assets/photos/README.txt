Photo slots for Sarkari mode
----------------------------
Drop images here with these exact names and they appear in the matching slot:

  slot1.jpg   banner, right side (the "Hon'ble" slot)
  slot2.jpg   carousel, left
  slot3.jpg   carousel, middle
  slot4.jpg   carousel, right
  logo.png    banner, left (use your own logo; do not use the State Emblem of India, its use is restricted by law)

.jpg or .png both work if you rename the extension in assets/sarkari.css (search for "photos/").
If a file is missing, the dashed placeholder stays.
